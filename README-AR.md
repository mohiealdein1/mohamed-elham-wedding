# دعوة زفاف إلهام ومحمد

موقع دعوة زفاف بتصميم مخصص مستوحى من ورق الدعوات الفاخر والزخارف النباتية المقصوصة من الورق. الموقع يعرض تفاصيل الفرح فقط؛ **لا يوجد نموذج تسجيل أو تأكيد حضور ولا يتم طلب أي بيانات من الزوار**.

## معلومات الدعوة

- العروسة: إلهام عبد الناصر — Elham Abdel Nasser
- العريس: محمد محيي الدين — Mohamed Mohie El Din
- العائلتان: آل هابابوا وآل غزاوي
- القاعة: Premiere Hall / قاعة بريمير
- المكان: Festival Land, New Assiut / فيستيفال لاند، أسيوط الجديدة
- الموعد: الساعة 8 مساءً
- خرائط جوجل: https://maps.app.goo.gl/SmfToVbjLVmfsbJP9
- الآية: ثابتة باللغة العربية سواء كانت لغة الموقع عربية أو إنجليزية.

لم يصل تاريخ الفرح ضمن التفاصيل، لذلك لن يظهر حقل التاريخ حتى يتم إدخاله.

## تشغيل الموقع

**أسرع طريقة:** فك ضغط الملف، وافتح `index.html` بمتصفح حديث مثل Chrome أو Edge.

**طريقة بديلة على الكمبيوتر:** افتح الطرفية داخل مجلد المشروع وشغّل:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## تعديل تاريخ الفرح لاحقًا

افتح `config.js` وعدّل السطر التالي باستخدام التاريخ الصحيح بصيغة `YYYY-MM-DD`:

```js
eventDate: ""
```

مثال توضيحي فقط: `eventDate: "2027-01-01"`. لا تستخدم المثال إلا إذا كان هو التاريخ الصحيح فعلًا.

## ملاحظات التصميم

- الواجهة باللغة العربية أو الإنجليزية وفقًا للغة المتصفح، ويمكن التبديل يدويًا من أعلى الصفحة.
- الآية القرآنية تظهر بالعربية في الحالتين.
- الخطوط العربية والإنجليزية منفصلة، مع خطوط بديلة إذا لم يتوفر الاتصال بخطوط Google Fonts.
- الزخارف SVG مرسومة داخل المشروع، بأشكال مسطحة متعددة الطبقات لمحاكاة الورق المقصوص؛ لا توجد صور ورود فوتوغرافية أو صور مولدة.
- CSS متجاوب للموبايل والتابلت واللابتوب، ويقلل الحركة عند تفعيل إعداد تقليل الحركة في الجهاز.
- رابط خرائط جوجل يفتح في نافذة جديدة.

## قبل النشر العام

1. أضف تاريخ الفرح بعد التأكد منه.
2. راجع تهجئة الأسماء الإنجليزية والعائلتين.
3. افتح الموقع على هاتف صغير، وهاتف كبير، وتابلت، ولابتوب.
4. انشر الملفات على استضافة HTTPS إذا أردت رابطًا عامًا قابلًا للمشاركة.
